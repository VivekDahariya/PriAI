# Roadmap

**Status:** Active

**Version:** 1.0

---

# Purpose

This document outlines the planned evolution of PriAI.

It serves as a development roadmap by defining the major milestones and feature sets for each version.

The roadmap helps maintain focus on incremental progress while avoiding unnecessary scope expansion.

---

# Version 1 — Foundation

## Objective

Build a private, offline, domain-specific AI assistant capable of answering questions using user-provided knowledge.

### Features

- Desktop application
- Create multiple AI assistants
- Import PDF and TXT files
- Build AI from uploaded knowledge
- Local knowledge storage
- Natural language question answering
- Source-grounded responses
- AI management
- Offline operation
- Modern desktop interface

**Status:** In Progress

---

# Version 2 — Knowledge Expansion

## Objective

Expand supported knowledge formats and improve retrieval quality.

### Planned Features

- DOCX support
- PPTX support
- OCR for scanned PDFs
- Image understanding
- Better document parsing
- Faster rebuilding
- Improved search quality
- Export and Import AI

**Status:** Planned

---

# Version 3 — Smarter AI

## Objective

Increase intelligence and usability without sacrificing privacy.

### Planned Features

- Conversation memory
- Multi-document reasoning
- Knowledge summarization
- AI-generated quizzes
- Flashcard generation
- Better explanations
- Advanced citations

**Status:** Planned

---

# Version 4 — Collaboration

## Objective

Enable teams and organizations to build shared knowledge assistants.

### Planned Features

- Team workspaces
- Shared AI projects
- Permission management
- Cloud synchronization (Optional)
- Version history
- AI sharing

**Status:** Planned

---

# Long-Term Vision

PriAI aims to become the easiest way to transform personal or organizational knowledge into a private AI assistant.

Whether the knowledge consists of textbooks, research papers, manuals, documentation, or personal notes, users should be able to create an AI that understands their information while keeping it under their control.

---

# Guiding Principles

Every future version of PriAI should preserve the following principles:

- Privacy First
- Offline First
- User-Owned Knowledge
- Source-Grounded Responses
- Simple User Experience
- Modular Architecture

---

# Success Criteria

PriAI will be considered successful if it enables users to:

- Find answers faster than manual document search.
- Trust the answers through source citations.
- Build AI assistants without technical expertise.
- Continue using their AI without requiring an internet connection.
